# ADR 0001：目标平台、运行范围与便携性

- 状态：已接受
- 日期：2026-11-15

## 背景

用户需要一个类似 AGMP 的 Factorio 工具，但只服务于 Factorio 2.1，并希望是便携版程序。

## 决策

1. 程序名为 **ModpackBuilder**，中文显示名 **模组包创建器**。
2. 仅发布 Windows 版本；macOS/Linux 暂不支持，代码不承诺跨平台路径行为。
3. 只面向 Factorio **2.1** 大版本。`info.json` 中生成的 `factorio_version` 固定为 `"2.1"`。
4. 程序为便携式单文件 exe，不需要安装器。
5. 运行时只允许写入两个位置：
   - Factorio mods 目录（默认 `%APPDATA%\Factorio\mods`，可用 `--mods-dir` 覆盖）
   - 程序所在目录（配置文件与备份）
6. 不写注册表，不写 `%APPDATA%` 下的工具配置，不写程序目录以外的日志或缓存。
7. 程序界面支持英文与简体中文；首次启动必须选择语言，选择结果保存到程序目录 `config.json`。后续启动读取该文件。
8. 检测到 Factorio 正在运行时，程序只显示提示并退出，不进行扫描或写入。

## 后果

- 便携性明确，但程序目录必须可写；放在只读目录时备份和语言配置会失败。
- 不提供 macOS 构建；跨平台需求出现时需要重新评估路径、进程检测和发布方式。
- Factorio 2.2 及以后版本不受支持，升级游戏大版本后需要修改工具。
