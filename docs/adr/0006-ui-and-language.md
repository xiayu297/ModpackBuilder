# ADR 0006：终端界面与语言

- 状态：已接受
- 日期：2026-11-15

## 决策

1. 使用 `inquire` 构建交互式终端界面，包括：
   - 主菜单（新建/编辑/删除/退出）
   - 语言选择
   - 成员多选
   - 文本输入与确认
2. 成员搜索采用“先输入过滤词，再进行多选”的方式，匹配内部名和显示标题，大小写不敏感；不实现实时模糊搜索。
3. 界面语言仅英文和简体中文。
4. 首次启动选择语言并写入程序目录 `config.json`；后续启动自动读取。
5. `--lang en|zh-CN` 可临时覆盖，不修改已保存设置。
6. 所有界面提示、菜单、错误摘要均按当前语言显示；底层错误细节可能保留英文。
7. 仅控制台输出，不写日志文件。
8. 主菜单在“退出”前提供“设置”，仅包含“界面语言”和“备份保留天数”两项，不提供额外设置。
9. 设置保存到 exe 同目录 `config.json`；未使用对应 CLI 覆盖时，语言立即切换，备份保留天数立即成为本次运行的生效值。
10. 若启动时显式使用 `--lang` 或 `--backup-days`，对应 CLI 值在本次运行中始终优先；设置中保存的新值只作为以后不带该参数启动时的默认值，并在界面中说明。
11. 备份保留天数直接输入非负整数，`0` 表示不自动清理，默认值为 `7`。
12. 修改保留天数时不立即删除备份，仍在启动及成功增删改后按当前生效值清理。
13. 创建和编辑流程在输入显示标题后，单次询问是否添加 `⚙️` 前缀，不保存为设置；默认保留输入标题当前的前缀状态，选择“是”统一为 `⚙️ 标题` 且不重复添加，选择“否”移除已有前缀。最终标题包括前缀在内仍最多 100 字符。

## 后果

- 依赖较轻，终端兼容性好；搜索体验是“过滤后多选”，不是实时搜索。
- 配置文件与备份都在程序目录，符合便携要求。
