# ADR 0004：mod-list.json 的原格式追加与删除

- 状态：已接受
- 日期：2026-11-15

## 背景

Factorio 写出的 `mod-list.json` 可能包含特殊格式：开头空行、LF/CRLF、条目间空白行等。用户要求“只追加”，不能重排或改写已有内容。

## 决策

1. 创建模组包时，在 `mod-list.json` 的 `mods` 数组**末尾插入**一条：
   ```json
   {
     "name": "<内部名>",
     "enabled": false
   }
   ```
2. 采用**字节保留插入**：
   - 读取原始字节，保留 UTF-8 BOM
   - 定位 `mods` 数组的结束位置
   - 复用原文件的缩进、条目间隔、换行符风格
   - 只插入新对象，不修改任何已有字节
   - 插入后重新解析 JSON 校验，失败则中止且不写文件
3. 已存在同名条目时，文件保持完全不变，不改 `enabled`。
4. 新条目追加在数组末尾，不排序。
5. 删除模组包时，允许对该条目做**字节保留移除**：只移除目标对象及相邻逗号，其他字节不动；同样在写前校验。
6. 每次实际写入前备份 `mod-list.json`；写入采用同目录临时文件 + 原子替换。
7. 若文件结构不符合预期（非法 JSON、找不到 `mods` 数组等），中止并提示，绝不使用“重新序列化”兜底。
8. Factorio 在自身运行时会重写该文件；本工具检测到游戏运行即退出，降低并发写风险。

## 后果

- `mod-list.json` 的 diff 只有新增/删除的条目，便于审计和回滚。
- 需要维护一个小型 JSON 文本定位器和多种格式变体测试。
- 删除操作是本工具唯一会移除 `mod-list.json` 条目的场景，且仅针对带 marker 的模组包。
