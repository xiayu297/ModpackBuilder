# ADR 0005：备份、编辑与删除

- 状态：已接受
- 日期：2026-11-15

## 决策

### 备份

1. 备份目录为程序目录下的 `backups/`。
2. 写入 `mod-list.json` 前备份为 `backups/mod-list-<时间戳>.json`。
3. 覆盖、编辑或删除模组包 zip 前，复制到 `backups/`，备份名为 `<原文件名>.<时间戳>.bak`。
4. 启动时清理超过 `--backup-days`（默认 7 天）的备份；`0` 表示不自动清理。
5. 备份失败时中止对应写操作。
6. 主菜单“设置”可修改保留天数并保存到 `config.json`；保存时不立即清理。未使用 `--backup-days` 时新值立即生效，显式 CLI 覆盖则仅在本次运行中继续优先。

### 创建

1. 内部名不得与已安装模组、内置/DLC 模组或已有模组包重名（大小写不敏感）。
2. 创建始终要求新的内部名；若内部名已存在，提示使用“编辑”，不提供覆盖或自动递增，避免在创建流程中改写已有模组包。
3. 若目标 `<内部名>_<版本>.zip` 已存在但未被识别为可编辑模组包，创建中止并保持原文件不变，由用户手工检查或选择其他名称/版本。
4. 新建不预选任何成员；零成员禁止生成。

### 编辑

1. 只能编辑带有效 marker 的 zip 模组包。
2. 内部名锁定，防止破坏 mod-list 身份；显示标题、成员、版本、作者可改。
3. 从 marker 读取成员并预勾选；已卸载的成员默认保留并标记“缺失”，用户可手动移除。
4. 保存后只保留该内部名的最新 zip；旧 zip 先备份再移出 mods 目录。
5. `mod-list.json` 中已有条目保持原 `enabled` 状态；若条目缺失则追加为 `false`。

### 删除

1. 只能删除带有效 marker 的 zip 模组包。
2. 删除前备份 zip 与 `mod-list.json`。
3. 删除 zip，并按原格式移除对应 `mod-list.json` 条目。
4. 不删除、不禁用任何成员模组。
5. 文件夹形式的合集可被识别，但不支持编辑/删除，避免误删目录。

## 后果

- 7 天内可以手工从备份恢复。
- 游戏内删除仍是普通模组行为；工具不保留外部注册表。
- 编辑以“更新同一内部名”的方式工作，不直接改内部名。
